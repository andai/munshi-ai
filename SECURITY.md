# Security Policy

## Reporting a vulnerability

**Please do not report security vulnerabilities through public GitHub issues, discussions or
pull requests.**

Report them privately through GitHub's private vulnerability reporting: open the repository's
**Security** tab and choose **Report a vulnerability**
(<https://github.com/andai/munshi-ai/security/advisories/new>). This creates a private
security advisory that only you and the maintainers can see. Please include:

- a description of the vulnerability and its impact,
- steps to reproduce or a proof of concept,
- the affected versions or components, and
- any suggested mitigation.

We will acknowledge your report within 5 business days, keep you informed while we investigate
and fix it, and agree a disclosure date with you before the advisory is published.

## Supported versions

munshi.ai is in early development. Security fixes are applied to the `development` branch and
released through `main`; please test against the latest `main` before reporting.
