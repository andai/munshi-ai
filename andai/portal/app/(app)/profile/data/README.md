# /profile/data

"Your data": ask for a copy of what munshi.ai holds about the signed-in person in this organisation
(their account, the meetings they own with transcripts, minutes and recordings), watch it being
prepared, and download the zip while it is available (POST/GET /api/v1/me/exports,
GET /api/v1/exports/{id}/download). A copy an admin asked for on their behalf is listed too.
