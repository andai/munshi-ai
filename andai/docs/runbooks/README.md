# andai/docs/runbooks

Operator runbooks: `alerts.md` (every Prometheus alert: what it means, first checks, silencing),
`canaries.md` (canary joins, `/metrics`, alert mail), `bot-hotfix.md` (shipping a
bot-only fix and rolling it back), `key-rotation.md` (rotating the key-encryption key: re-wrap,
`kek-status`, retiring the old key) and `tenant-admission.md` (draft guide for customer tenant
admins: Teams external-bot and lobby policy, Meet admission, Zoom waiting room).
